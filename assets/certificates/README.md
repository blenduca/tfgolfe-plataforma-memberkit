# Certificados TF Golfe

Frente e verso exportados do kit de artes do template Memberkit, com a identidade TF Golfe, em PNG de **1056 × 816 px**. O template coringa não foi alterado.

| Curso | Frente | Verso | Carga horária impressa nesta prévia |
|---|---|---|---|
| Formação RH Estratégico | `rh-estrategico-certificado-frente.png` | `rh-estrategico-certificado-verso.png` | 3 h |
| DIRF Sem Segredo | `dirf-digital-certificado-frente.png` | `dirf-digital-certificado-verso.png` | 10 h |
| Atualizações Trabalhistas | `atualizacoes-trabalhistas-certificado-frente.png` | `atualizacoes-trabalhistas-certificado-verso.png` | 3 h |

As cargas horárias são **provisórias**, arredondadas para cima a partir das durações das aulas cadastradas no protótipo. Confirme as cargas oficiais antes de cadastrar as artes na Memberkit. A arte traz o nome de Tatiana Golfe sob uma linha de assinatura; nenhuma assinatura manuscrita foi adicionada.

## Campos dinâmicos na Memberkit

O PNG da frente deixa os campos vazios para a Memberkit inserir os dados do aluno:

| Campo | Posição (x, y) | Área | Sugestão |
|---|---:|---:|---|
| Nome do aluno | 148, 298 | 760 × 72 | Allura ou Helvetica, 40–48 px, `#003366` |
| Data de conclusão | 438, 538 | 180 × 28 | Helvetica, 15 px, `#262626` |
| QR Code | 852, 594 | 112 × 112 | QR Code de validação |

O verso contém o programa resumido de cada curso. Os cursos sem aulas no protótipo não receberam certificado nesta exportação.
